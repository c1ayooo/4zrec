# 小程序安全测试检查清单

六阶段全量清单。逐项过，确认项回写测试项账本（miniprogram_test_item_update）。

## 阶段0 取包

- □ 包来源判定：PC 微信 4.x radium / 3.x Applet / Android / 上传
- □ 加密判定：V1MMWX 前缀 → 需 AppID（目录名）解密
- □ 主包/分包识别：分包单独上传会缺 app.json，多包一起上传自动合并

## 阶段1 解包还原

- □ 解包成功、文件数正常（file_count=0 说明挂起待补 AppID）
- □ 分包覆盖清单审查（同名覆盖 = 隐蔽逻辑替换线索）
- □ app.json：pages/subpackages/plugins/permission 提取
- □ 插件、Worker、WASM、开放数据域是否单独存在（平台不解，需手工兜底）

## 阶段2 静态审计

- □ AppID/AppSecret/ accessToken / 硬编码密钥提取并验真（miniapp_verify / cloud_key_verify / llm_key_verify）
- □ 内网域名、管理端接口、第三方服务凭证
- □ 统一请求层定位：鉴权头 / 签名算法 / 加密逻辑 / 防重放字段
- □ 登录态处理：wx.login 的 code 去向、token 存储与形态、openid 是否参与前端鉴权
- □ 跳转面：navigateTo/redirectTo/web-view 的 URL 来源

## 阶段3 登录态与敏感数据链

- □ 凭据验真（jscode2session 旁路：40029=凭据已验真）
- □ js_code 获取（抓包 wx.login）→ session_key 换取
- □ encryptedData+iv 解密（AES-128-CBC）→ 手机号/unionId，水印 appid 核对
- □ 会话伪造与越权验证（显式授权下；A/B 账号对比）
- □ 报告分离「接口可用性」与「是否伪造他人身份」

## 阶段4 接口与业务

- □ 全部端点无凭据重放（http_probe）
- □ 横向越权（资源 ID 替换）与纵向越权（管理接口）
- □ 云函数直调与传参越权；云数据库集合权限矩阵；云存储遍历；env+匿名登录
- □ 支付：金额/数量/优惠篡改、状态机跳步、回调验签（最小金额自建订单）
- □ 验证码枚举/频控；签到抽奖批量与防重放真校验

## 阶段5 客户端攻击面

- □ web-view 任意跳转与白名单绕过
- □ JSBridge 升级链（H5 XSS → postMessage/navigateTo）
- □ 小程序码 scene 注入与跳转劫持
- □ 分享 path/query 落地参数污染

## 阶段6 报告销账

- □ 每发现标注页面路径/接口/参数/触发方式
- □ 漏洞类型用标准枚举（小程序逻辑缺陷/接口未授权/任意跳转/支付漏洞/源码泄露/云函数未授权/敏感数据泄露）
- □ 账本逐项回写终态；confirmed 落 record_vulnerability；弱信号 upsert_project_fact
- □ 敏感字段脱敏（手机号形态化、session_key/openid 不整串粘贴）

## 授权边界（硬约束）

- 仅测试授权目标；主动利用（会话伪造/越权/支付篡改）必须显式授权依据
- 不批量拉取用户数据；不碰真实他人交易
- 平台自身账号/会话/Token 是运维资产，禁止读取修改伪造
